# Glyph NFC Pay — анимация Glyph при оплате (Nothing Phone (2))

Android-приложение, которое при оплате телефоном (СберПэй, Mir Pay, Google Кошелёк, Т-Банк и др.)
запускает анимацию на Glyph Interface Nothing Phone (2).

В репозитории два проекта:

| Папка | Что это |
|-------|---------|
| `android/` | Android-приложение (Kotlin + официальный Nothing Glyph SDK) |
| `src/` (корень) | Веб-страница с симулятором анимации и инструкцией (React + Vite) |
| `.github/workflows/build-android.yml` | Сборка APK в GitHub Actions |

## Как это работает

Android не позволяет стороннему приложению увидеть NFC-платёж напрямую, поэтому приложение
слушает **уведомления** банков/кошельков (`NotificationListenerService`). Как только приходит уведомление
вида «Покупка 349 ₽…», запускается анимация.

Glyph SDK работает только когда приложение на переднем плане. Поэтому на 3–4 секунды
показывается невидимая прозрачная `GlyphActivity` (не перехватывает касания, сама закрывается).
Для её запуска из фона нужно разрешение «Поверх других окон».

Стили анимации: **Оплата прошла** (волны от камеры → заливка → двойная вспышка → затухание),
**Комета**, **Дыхание**, **Искры**, **Случайная**. Яркость настраивается.

## Сборка в GitHub Actions

1. Создайте репозиторий на GitHub и загрузите проект:
   ```bash
   git init
   git add .
   git commit -m "Glyph NFC Pay"
   git branch -M main
   git remote add origin https://github.com/<ваш-логин>/glyph-nfc-pay.git
   git push -u origin main
   ```
2. Вкладка **Actions → Build Android APK**. Через 3–5 минут внизу страницы запуска появится
   артефакт **GlyphNfcPay-apk** (ZIP с `GlyphNfcPay-release.apk` и `GlyphNfcPay-debug.apk`).
3. Для релиза со ссылкой на APK:
   ```bash
   git tag v1.0.0
   git push origin v1.0.0
   ```
   APK появится в **Releases**.
4. (Необязательно) Свой API-ключ Nothing: *Settings → Secrets and variables → Actions →
   New repository secret* → `NOTHING_API_KEY`. Без него используется ключ `test`.

Локально: откройте папку `android/` в Android Studio и нажмите Run.

## Установка и использование

1. **Установите APK** на Nothing Phone (2) (Android 14+). Разрешите установку из неизвестных источников.
2. **Включите Glyph SDK для приложения.** Подключите телефон к ПК (отладка по USB) и выполните:
   ```bash
   adb shell settings put global nt_glyph_interface_debug_enable 1
   ```
   Придёт уведомление об активации. Режим выключается через 48 часов — команду нужно повторять.
   На Android 16 (Nothing OS 4.0+) ключ не требуется (приложение собрано с targetSdk 36).
   Постоянный вариант — получить API-ключ у Nothing и добавить в секрет `NOTHING_API_KEY`.
3. **Откройте приложение** и нажмите **«0. Разрешить ограниченные настройки»** →
   ⋮ вверху справа → «Разрешить ограниченные настройки» (Android 13+ блокирует доступ к уведомлениям
   для APK, установленных вручную).
4. Выдайте три разрешения (кнопки 1–3): **доступ к уведомлениям**, **поверх других окон**,
   **работа в фоне**. Все три строки должны стать ✅.
5. Нажмите **«▶ Проверить анимацию»** — Glyph сразу проиграет выбранный стиль.
6. Нажмите **«💳 Тест как при оплате (через 5 с)»**, сверните приложение — анимация запустится
   так же, как при настоящей оплате.
7. Оплачивайте телефоном. В блоке «Последнее срабатывание» видно, какое приложение сработало.

Если ваш банк не в списке — добавьте его `package name` в поле «Свои приложения»
(через запятую). Поддерживаются «из коробки»: СберБанк Онлайн, Mir Pay, Google Кошелёк, Т-Банк,
ВТБ, Альфа-Банк, Газпромбанк, Райффайзен, Яндекс Банк, Ozon Банк, QIWI и SMS от 900.

## Если что-то не работает

* **«Не удалось подключиться к Glyph»** — повторите adb-команду (debug-режим живёт 48 ч), перезапустите приложение.
* **Тест работает, оплата — нет** — проверьте три разрешения; посмотрите «Последнее срабатывание».
  Если пусто — банк шлёт уведомление из другого приложения, добавьте его package name.
* **Тест «через 5 с» не запускается из фона** — нужно «Поверх других окон» и снятые ограничения батареи;
  закрепите приложение в «Недавних» (замок).
* **Ограничение** — приложение не отличает NFC-оплату от других покупок, о которых банк присылает уведомление.
  Возвраты, входящие переводы и коды подтверждения игнорируются. Повторы в течение 6 секунд подавляются.

## Структура Android-проекта

```
android/app/src/main/java/com/glyphpay/nfc/
├── MainActivity.kt           # экран настроек, кнопки тестов
├── PaymentListenerService.kt # слушает уведомления
├── PaymentDetector.kt        # правила: какие уведомления считать оплатой
├── GlyphLauncher.kt          # запуск прозрачной Activity из фона
├── GlyphActivity.kt          # невидимая Activity, проигрывает анимацию
├── GlyphController.kt        # обёртка над Glyph SDK
├── GlyphAnimations.kt        # формулы анимаций для 33 сегментов Phone (2)
└── Prefs.kt                  # настройки
android/app/libs/glyph-sdk.aar # Nothing Glyph Developer Kit
```

Каналы Phone (2): `A1=0, A2=1, B1=2, C1_1..C1_16=3..18, C2..C6=19..23, E1=24, D1_1..D1_8=25..32`.
