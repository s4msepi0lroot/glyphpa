# Glyph Pay — анимация Glyph при NFC-оплате (Nothing Phone (2))

Android-приложение, которое зажигает Glyph на задней панели Nothing Phone (2), когда вы платите телефоном
(СберПэй, Mir Pay, Google Кошелёк, Т-Банк, ВТБ и др.).

```
android/                     Android-проект (Kotlin, Glyph SDK лежит в app/libs)
.github/workflows/android.yml  Сборка APK в GitHub Actions
src/                         Сайт-презентация с живым симулятором Glyph
```

## Как это работает

1. Android не сообщает обычным приложениям «NFC-оплата прошла», поэтому приложение читает **уведомления** банков
   и кошельков (`NotificationListenerService`) и ищет в них слова «оплата / покупка / списание / payment…».
   Пополнения, переводы, возвраты и кэшбэк игнорируются.
2. Glyph SDK работает **только из активного приложения**, поэтому при оплате на ~3 секунды открывается
   полностью прозрачное окно без фокуса и касаний (нужно разрешение «Поверх других окон»).
3. Внутри окна 33 сегмента Glyph Phone (2) управляются покадрово через `GlyphManager.setFrameColors()`.

Анимация стартует через 1–3 секунды после касания — когда банк присылает push.

## Инструкция по использованию

1. **Установите APK** (`GlyphPay-release.apk`), разрешив установку из неизвестных источников.
2. Откройте **Glyph Pay** и выдайте три доступа (индикаторы станут зелёными):
   - **Доступ к уведомлениям** → включить «Glyph Pay».
     Если переключатель серый: Настройки → Приложения → Glyph Pay → ⋮ → *Разрешить ограниченные настройки*.
   - **Поверх других окон** → разрешить.
   - **Работа в фоне** → «Без ограничений».
3. Выберите анимацию — по нажатию она сразу проигрывается. Настройте яркость.
4. Нажмите **«▶ Проверить анимацию»** — Glyph должен загореться.
5. Нажмите **«Тест как при оплате»**, сверните приложение или заблокируйте экран — через 5 секунд Glyph
   загорится (проверка работы из фона).
6. Платите телефоном. Если банка нет в списке — **«Выбрать приложения оплаты»**.

### Если Glyph не загорается

- **Nothing OS 4.0 / Android 16:** ключ API не нужен, достаточно включённого Glyph в настройках.
- **Более старые версии:** включите отладку Glyph с компьютера (действует 48 часов, затем повторить):

  ```bash
  adb shell settings put global nt_glyph_interface_debug_enable 1
  ```

### Если при оплате ничего не происходит

Откройте блок **«Журнал»** внизу приложения:
- «пропущено (не похоже на оплату)» → выключите переключатель «Только уведомления об оплате»;
- журнал пуст → в банке выключены push об операциях или приложение банка не выбрано в списке приложений.

## Сборка

### GitHub Actions

```bash
git init && git add . && git commit -m "Glyph Pay"
git branch -M main
git remote add origin https://github.com/<ваш-ник>/glyph-pay.git
git push -u origin main
```

GitHub → **Actions** → *Build Android APK* → **Artifacts → GlyphPay-apk**.
Чтобы получить APK в Releases: `git tag v1.0.0 && git push --tags`.

### Локально

Нужны JDK 17 и Android SDK 36 (или откройте `android/` в Android Studio):

```bash
cd android
./gradlew assembleRelease
# app/build/outputs/apk/release/GlyphPay-release.apk
```

## Сайт-презентация

```bash
npm install
npm run dev     # разработка
npm run build   # сборка в dist/
```
